# 政策工具编码手册 v0.1.0

本手册用于把中文政策文本编码为可统计的政策工具变量。框架采用
Rothwell & Zegveld（1985）的三分法，这是公共政策研究中引用最广的政策工具分类之一。

> 手册是**配置而非附属文档**：`pra/codebook/zegveld.yaml` 是唯一事实来源，
> 本文档解释判定逻辑；两者修改需同步。

## 一、框架说明

| 一级类目 | 核心逻辑 | 政府在做什么 |
|---|---|---|
| 供给型 | 政府直接提供资源与能力 | 给钱、给人、给技术、给服务、给信息 |
| 需求型 | 政府直接创造或调节需求 | 买、补、限、引 |
| 环境型 | 政府塑造外部制度环境 | 定目标、立规矩、给金融税收优惠、搞试点考核 |

三者的关键区别在于**作用点**：供给型作用于生产要素，需求型作用于市场，环境型作用于制度。

## 二、二级类目与判定规则

### 供给型

| 二级类目 | 判定规则 | 典型线索 |
|---|---|---|
| 资金投入 | 出现明确的财政资金安排 | 财政拨款、专项资金、经费保障、以奖代补 |
| 人才培养 | 涉及人的培养、引进、职业发展 | 人才引进、培训、学科建设、继续教育 |
| 技术支持 | 涉及技术研发与创新平台 | 关键技术、科技攻关、创新平台、成果转化 |
| 公共服务 | 涉及设施、网络、服务供给能力 | 基础设施建设、服务网络、便民服务 |
| 信息支持 | 涉及信息流动与监测 | 信息公开、数据共享、统计监测、科普 |

### 需求型

| 二级类目 | 判定规则 | 典型线索 |
|---|---|---|
| 政府采购 | 政府作为买方 | 政府购买服务、集中采购、首台套 |
| 价格补贴 | 通过价格或支付影响需求 | 消费补贴、医保支付、集中带量采购 |
| 贸易管制 | 进出口与准入限制 | 关税、负面清单、许可管理 |
| 海外交流 | 跨境合作与走出去 | 国际合作、跨境、引进来 |

### 环境型

| 二级类目 | 判定规则 | 典型线索 |
|---|---|---|
| 目标规划 | 设定目标、指标、时间表 | 规划、纲要、行动方案、路线图 |
| 法规管制 | 设定规则、标准、监管与处罚 | 管理办法、监督管理、执法、准入退出 |
| 金融支持 | 信贷、保险、基金等融资安排 | 信贷、融资担保、产业基金 |
| 税收优惠 | 税收减免与税率调整 | 免征、税前扣除、增值税 |
| 策略性措施 | 试点、考核、协调机制 | 试点示范、考核评价、联席会议 |

## 三、边界案例处理

1. **「鼓励社会资本设立产业基金」** → 金融支持（环境型），不是资金投入（供给型）。
   区分标准：钱来自财政还是市场。
2. **「严禁以设立基金名义变相举债」** → 法规管制。否定语境下不计入金融支持；
   规则编码器会自动降低置信度并在 `note` 中标注「否定语境」。
3. **「开展试点示范」** → 策略性措施。即使试点内容涉及资金，仍以试点本身为主类目。
4. **「制定管理办法，加强监督管理」** → 一条「法规管制」，不重复计数。
5. **同一段落同时出现多类工具** → 允许并列编码，这正是「政策组合」分析的输入。

## 四、编码流程（论文方法部分可用）

1. **抽样框**：说明语料来源、检索式、时间范围、纳排标准。
2. **预处理**：正文抽取、去页眉页脚、去除附件表格。
3. **机器初筛**：规则基线（可复现）或 LLM 辅助（需报告模型版本与 prompt）。
4. **人工复核**：对全部或抽样比例（建议 ≥ 20%）逐条确认，误报删除、漏报补录。
5. **信度检验**：至少两名编码员独立编码同一子样本，报告 Krippendorff's α。
6. **分歧处理**：记录分歧 → 讨论 → 修订手册 → 重编码，修订过程本身写入附录。

## 五、信度报告模板

> 两名编码员对随机抽取的 N 篇政策文本（占语料 X%）进行独立编码，
> 编码单元为「文档 × 二级类目」的存在/不存在判定。
> 一致性为 Krippendorff's α = __（95% CI __–__），达到可接受水平（α ≥ 0.80）。
> 分歧集中于「策略性措施」与「目标规划」的边界，经讨论后修订了手册第 3.2 条判定规则。

## 六、已知局限

- 关键词法对**隐含表达**（如「加大投入力度」未指明财政）不敏感，会低估供给型工具。
- 中文政策文本常出现「一揽子」表述，段落级编码可能高估工具密度。
- 三分法本身受批评为「重形式轻强度」，建议辅以**政策力度**（发文层级 × 工具数量）作为补充变量。
